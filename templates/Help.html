When you submit a file, VirusGuard immediately generates an immutable cryptographic SHA-256 hash. It queries VirusTotal API v3 telemetry across 70+ antivirus engines. If malicious signatures are identified, Llama 3 70B (via Groq Cloud) parses low-level engine tags into structured plain-English guidance.

No. VirusGuard strictly adheres to ephemeral data practices. Uploaded binaries are written with randomized names to an isolated quarantine folder and wiped immediately once analysis is complete. We do not retain copies of your files.

Files up to 32MB are supported directly. VirusGuard handles executables (.exe, .dll, .bin), archives (.zip, .7z, .tar, .gz), office documents (.pdf, .docx, .xlsx), and script payloads (.py, .js, .sh, .bat).

When configured via the ALERT_RECIPIENT_EMAIL environment variable, automated SOC alerts are dispatched via SMTP whenever a sample registers malicious engine signatures.
