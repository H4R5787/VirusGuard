Rapid Host Containment Protocol

If active malware or ransomware is suspected in your network, execute immediately:

  • Sever Network Interfaces: Disconnect all Ethernet cables and disable Wi-Fi/Bluetooth adapters immediately.
  • Preserve Volatile RAM: Do not power down or reboot hosts; volatile memory contains cryptographic keys and process artifacts.
  • Isolate Backup Shares: Immediately unmount offline storage and revoke admin credentials to prevent lateral encryption.
